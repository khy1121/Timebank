# G0 문제 진술 — todobank (가칭)

## 한 문장
미룬 할 일은 목록에서 조용히 쌓일 뿐 "미룬 비용"이 보이지 않아서, 계속 미루게 된다.

## 지금 어떻게 때우고 있나
- 투두 앱의 "기한 지남" 빨간 표시 → 익숙해지면 무시한다
- 밀린 일을 통째로 다음 날로 넘기기, 목록 갈아엎기
- 친구에게 선언하기, 벌금 내기 같은 수동 강제 장치

## 경쟁이 놓친 지점
기존 앱은 미룬 일을 **상태**(지남/안 지남)로만 보여준다. 미룬 기간이 **누적 비용**으로 커지는 것을 보여주는 앱은 검색되지 않았다.
- 28 Tasks Later: 밀린 일이 "좀비"가 되어 목록을 어지럽힘 — 비용이 숫자로 커지지 않음
- PastDue: 1·3·7일 뒤 알림 강도만 올라감
- Remember The Milk 커뮤니티 제안: 하루 밀릴 때마다 경고 기호 1개(최대 5개) — 정식 기능 아님

## 컨셉
할 일마다 원금(가상 금액)이 있고, 기한을 넘기면 하루 단위 복리 이자가 붙는다. 끝내면 상환. 총 부채와 신용등급이 첫 화면에 보인다. 실제 돈은 오가지 않는다.

## 아직 비어 있는 것 (정직하게)
- 이 문제를 직접 겪는다고 말한 실명 사용자: **0명** — 본인 포함 3명 이상 확보 필요
- "부채" 은유가 동기가 되는지, 스트레스가 되어 앱을 지우게 하는지 모름
