# G2 MVP 스코프 — 할 일 이자 (가칭)

소프트 론칭 상한: **6주**. 넘칠 것 같으면 일정이 아니라 범위를 자른다.

## build (3개)
1. **할 일 + 이자 엔진**: 추가(제목·원금·기한), 완료(상환), 기한 초과 시 일 복리 계산, 첫 화면에 총 부채·신용등급
2. **계정 + 동기화**: 이메일 인증 로그인, 서버 저장, 본인 데이터만 접근
3. **이자 알림**: 기한 당일, 이자가 붙기 시작한 날 로컬 알림

이자 규칙 초안(L0 결과로 조정): 원금 1,000~5,000냥(중요도 5단계), 일 10% 복리, 상한 원금의 10배.

## fake / manual

## 제외 + 되살릴 조건
| 항목 | 되살릴 조건 |
|---|---|
| 홈 화면 위젯 | 주간 재방문 사용자 50명 이상 |
| 부채 현황 공유 카드 | 의견 중 "공유하고 싶다" 5건 이상 |
| 반복 할 일 | 같은 요청 5건 이상 |
| 소셜 로그인(구글·애플) | 가입 화면 이탈률 50% 초과 |
| 유료 결제 | 2주차 재방문율 20% 이상 |
| 친구와 부채 비교 | 주간 재방문 사용자 200명 이상 |

## 포기 불가 6항목
- 데이터 유실 방지: 서버 저장 + 오프라인 입력분 재전송
- 인증/권한: 행 단위 보안으로 본인 데이터만
- 결제 정확성: 결제 없음(해당 없음)
- 개인정보 최소화: 이메일만 수집, 처리방침 페이지, 계정 삭제 기능(스토어 심사 요건)
- 에러 로깅: Sentry, 사용자 ID 부착
- 접근성 기본: 글자 크기 대응, 스크린리더 라벨, 색만으로 상태 구분하지 않기

## 스택
- 앱: Expo (React Native, TypeScript) — 안드로이드·iOS 동시
- 백엔드: Supabase (Auth, Postgres, 행 단위 보안)
- 빌드·배포: EAS Build / Submit (윈도우에서 iOS 빌드 가능)
- 에러: Sentry
- 필요 비용: 구글 개발자 등록 25달러(1회), 애플 연 99달러

## G3 계측 (출시 전 구현)
- 이벤트 테이블 `events(user_id, event, ts, props)`
- 활성화 이벤트 1개: **이자가 붙은 할 일을 처음 상환**
- 가입일 + 유입 경로 저장
- 주간 집계 SQL 1개
- 피드백 채널: 매일 보는 메일함
- Sentry에 사용자 ID 부착

## 시리즈 공통화 메모
2번 앱부터 재사용할 것: 로그인, 이벤트 기록, 에러 로깅, 계정 삭제, 처리방침. 단, 1번 앱에서는 미리 공통 모듈로 빼지 않는다. 2번 앱에서 두 번째로 필요해질 때 추출한다.

## 확장: 성장 루프 (2026-11-23)

### 왜
냥이 빚 쪽에만 쓰여서, 잘했을 때 얻는 것이 없다. 처음의 신기함이 지나면 앱을 열 이유가 약해진다(이탈 우려, 사용자 제기).

### 증거
없음. 출시 전이라 재방문 데이터가 없다. "보상이 있으면 덜 떠난다"는 가설이고, 사용자 결정으로 출시 전에 최소판을 넣는다. 판단은 출시 후 2주차 재방문율과 구매 기록으로 한다.

### build (최소판, 약 1주)
| 항목 | 내용 |
|---|---|
| 냥 잔고 | 기한 안 상환 시 원금의 10%를 번다. 연체 이자는 잔고에서 빠지되 0 아래로 내려가지 않는다. 별도 저장 없이 상환 기록에서 계산 |
| 연속 기록 | 기한 안 상환 5번마다 1,000냥 보너스 |
| 상점 | 그림 자산 없이 코드로 그리는 꾸미기 9개: 도장 잉크, 도장 글자, 말풍선 색 |

build 3개 원칙을 넘는다. 이미 만든 3개(이자 엔진, 계정·동기화, 알림)에 더하는 것이라 일정은 1주 늘어난다. 사용자 결정으로 감수한다.

### 제외 + 되살릴 조건
| 항목 | 되살릴 조건 |
|---|---|
| 마스코트 옷·소품(그림 필요) | 상점 구매 사용자 30% 이상 또는 "더 사고 싶다" 의견 5건 |
| 은행 건물 성장 단계 | 2주차 재방문율 20% 이상 |
| 주간 결산 화면 | 주간 재방문 사용자 50명 이상 |
| 잔고로 이자 갚기(빚 탕감권) | "빚이 너무 커서 포기했다" 의견 5건 |

### 계측 (G3에 추가)
- 이벤트: `item_buy`(item_code, price), `repay`의 props에 `on_time`, `streak`
- 판단 지표: 상점을 한 번이라도 연 사용자 비율, 구매한 사용자 비율, 구매 사용자와 비구매 사용자의 2주차 재방문율 차이
