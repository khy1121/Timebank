# 할일통장

미루면 복리 이자가 붙는 할 일 앱. 미룬 비용을 "빚"이라는 숫자로 보여준다. 실제 돈은 오가지 않고, 앱 안의 가상 화폐 "냥"만 쓴다.

- 할 일마다 원금(중요도 1~5 × 1,000냥)을 건다.
- 기한을 넘기면 하루 10% 복리로 불어난다. 상한은 원금의 10배다.
- 끝내면 상환되어 "완납" 도장이 찍힌다.

## 실행
```bash
cd app
npm ci
cp .env.example .env   # Supabase 주소와 공개용 키를 채운다
npm run web            # http://localhost:8081
```

## 검사
```bash
cd app
npm test
npm run typecheck
npm run lint
```
